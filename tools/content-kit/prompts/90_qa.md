# 배치 검수 (QA)

아래는 "{{TYPE}}" 타입으로 생성된 배치다. 스타일 가이드의 **품질 체크리스트** 기준으로 검수하라.

<schema>
{{SCHEMA:{{TYPE}}}}
</schema>

<existing>
{{EXISTING}}
</existing>

<batch>
{{BATCH}}
</batch>

검수 항목:
1. 다른 게임 IP를 연상시키는 이름·설정
2. 배치 내부 중복(이름, 첫 문장, 컨셉) 및 `<existing>`과의 중복
3. 길이 규칙 위반(가이드 5절)
4. 문체 위반(평서체 아님, 이모지, 영어 병기, "당신")
5. 과금·현대 요소·고어 묘사
6. 논리 불일치(예: 몬스터 behavior와 weakness가 안 맞음, 스킬 combo_hint가 존재하지 않는 스킬을 가리킴)
7. 스키마 위반(필드 누락/추가, enum 밖의 값, 패턴 불일치)

출력 형식(JSON만):
{
  "verdict": "pass" | "fix" | "reject",
  "issues": [ { "id": "<항목 id>", "field": "<필드>", "rule": <1~7>, "note": "<무엇이 왜 문제인지 한 문장>" } ],
  "fixed_items": [ <문제가 있던 항목만, 수정된 완전한 객체> ]
}

- `fix`: 문제 항목을 고쳐서 `fixed_items`에 넣는다. 문제 없는 항목은 넣지 않는다.
- `reject`: 배치의 30% 이상이 규칙 1·5·7 위반이면 통째로 재생성이 낫다고 판단하고 fixed_items는 비운다.
- 수정은 **최소 변경**. 문제 없는 필드는 글자 하나도 바꾸지 않는다.
