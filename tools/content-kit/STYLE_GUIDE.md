# 판게아 RPG 콘텐츠 스타일 가이드 (월드 바이블)

> 이 문서는 모든 생성 프롬프트 앞에 그대로 붙여 넣는 "공통 전제"입니다.
> `[ ]` 칸은 코드(`game/data/*`)·문서(`docs/concept.md`)·기존 데이터에서 알아낸 값으로 채웠습니다.
> **`[확인 필요]`** 표시였던 항목은 9절에 운영자 결정이 적혀 있습니다. 생성 모델은 그 결정을 따릅니다.

## 1. 게임 개요
- 제목: 판게아 RPG (PANGAEA RPG, 구 TIDEBOUND). 화면 제목·로그·도감 모두 ‘판게아 RPG’.
- 장르: 끝없이 펼쳐지는 사냥 **방치형 RPG**. 플레이어는 몬스터를 자동 사냥하고, 스킬을 조합하고, 더 먼 지역으로 모험한다. 레벨이 차면 **환생**(최대 200회)으로 처음부터 다시 시작하며 세계석·연구·유물·도감을 이어 간다. 환생 100회부터 **승천**.
- 전투: 항상 1:1 턴제(2초 = 1턴). ‘무리’ 변종도 체력만 N배인 한 몸이다. 광역·아군 개념 없음.
- 플랫폼: 웹(모바일 폭 우선). 텍스트는 **좁은 화면에서 한눈에 읽히는 길이**가 기본.
- 과금 요소 없음(지인끼리 즐기는 비영리 게임). "유료", "결제", "패키지" 같은 어휘는 콘텐츠에 절대 등장하지 않는다.

## 2. 세계관 핵심
- 세계의 이름/구조: 하나의 대륙 **판게아**. **여러 게임의 세계가 하나의 대륙으로 이어졌다.** 모험가는 생을 거듭하며 모든 세계의 직업과 기술을 손에 넣는다(`docs/concept.md` 1절). 지금 구현된 세계는 **메이플 월드**(빅토리아 아일랜드~아케인 리버), **아제로스**(히든 계보·보스), **이계**(해커·요원·트레이더 계보). **다음에 여는 세계: 코프룰루 구역**(판게아 바다 너머, 하늘에 떠 있는 별의 바다. 부서진 궤도 정거장 · 결정 광맥 행성 · 생체 군체 늪 · 고대 빛의 성단). 이 세계의 지역·몬스터·직업·스킬 이름은 **판게아 고유**로 짓고 원작(스타크래프트) 고유명사·종족명·유닛명은 쓰지 않는다. 보류: 심해(옛 TIDEBOUND 바다).
- 시대감/문명 수준: 세계마다 다르다. 메이플 월드는 중세 판타지 + 버섯·달팽이의 동화풍, 커닝시티는 네온·지하철·배수로의 도시, 시간의 신전·아케인 리버는 신화적. 이계·해커 계보에는 서버·해킹·주식 같은 현대 어휘가 실제로 존재하고, **현대·SF 어휘는 모든 세계에서 허용**한다(결정 Q4). 코프룰루 구역은 함선·드론·결정·가스·궤도 같은 SF 어휘를 기본으로 쓴다.
- 핵심 갈등/배경 사건: “여러 세계가 하나의 대륙으로 이어진 날 이후로, 바다는 기억을 잃은 모험가들을 이 항구에 내려놓는다.” 판게아는 모험가를 죽게 두지 않고 처음(환생)으로 돌려보낸다. 1부(1~3장)는 **검은 마법사**까지, 2부(4~6장)는 그 뒤·승천의 이야기(`game/data/story.ts`).

- 금지된 요소: 과금·결제 어휘, 실존 종교·국가 명칭, 피·고어 직접 묘사, 이모지(로그 접두 ✦·👑·📖는 코드가 붙이므로 글에는 넣지 않음). 현대 어휘·기기는 허용(결정 Q4)하되, 메이플 월드 지역 글에서는 그 지역의 동화풍 어감을 해치지 않는 선에서만.

## 3. 톤 & 문체
- 기본 문체는 **칸마다 다르다**(기존 데이터 기준):
  - 몬스터 `lore`, 사냥터 `description`: **‘~다’ 평서체**, 짧은 명사구 허용. 좋음: `느리지만 포기하지 않는다. 모든 모험가의 첫 상대.` 나쁨: `느리지만 포기하지 않아요!`
  - 스킬 `desc`, 옵션 `description`, 칠흑 `desc`, 던전 `description`(일부): **‘~합니다/~됩니다’ 합쇼체**(시스템 설명 톤). 예: `물리 공격이 오르고, 상대를 쓰러뜨리면 모든 재사용 대기가 초기화됩니다.`
  - 스토리 `lines`: **1인칭 회상체 ‘~다/~였다’**, 대사는 “ ” 큰따옴표. 예: `파도 소리에 눈을 떴다. 낯선 선착장, 낯선 하늘.`
  - 스토리 `hint`, 업적·목표: **‘~한다’** 동사형. 예: `헤네시스 사냥터에 간다`
- 유머: 가볍게 허용(한 배치 안에서 10~15% 정도). 기존 예: `죽어서도 바나나를 놓지 않는다.` 과한 밈, 인터넷 유행어, 이모지 금지.
- 잔혹 묘사: 피·고어 직접 묘사 금지. "쓰러뜨리다", "처치하다", "사냥하다" 수준까지만. (기존 글에 ‘피 냄새’ 1회 정도의 간접 표현은 있음.)
- 2인칭 "당신"은 피하고, 필요하면 "모험가"로 부른다.
- 숫자는 아라비아 숫자, 단위는 붙여 쓴다. (`+12%`, `3초`, `5회`, `Lv.55`, `×2`)
- 영어 병기 금지(고유명사 포함). 영문은 사냥터 `subtitle`(`LITH HARBOR · PIER`)에만 쓴다. 외래어 한글 표기(스켈레톤 솔저, 파이널 피규레이션)는 허용.
- 가운뎃점 ‘ · ’(앞뒤 띄움)이 게임의 구분자다: `리스항구 · 선착장`, `수로의 왕 · 킹 슬라임`, `제1장 · 판게아의 문`.

## 4. 명명 규칙
- **IP 정책(결정 Q1)**: 기존 세계(메이플 월드·아제로스)는 원작 이름을 그대로 쓰고, **새 세계(코프룰루 구역부터)는 판게아 고유 이름**을 쓴다. 기존 데이터의 몬스터 58종·지역 9곳·보스·직업·스킬 이름이 메이플스토리 원작 이름인 것은 그대로 둔다.
  - 기존 세계(메이플 월드·아제로스)를 **확장**하는 배치: 원작 명칭을 쓴다(기존 데이터와 같은 방식). 단, 원작에 없는 것을 지어낼 때는 그 세계의 어감을 따르되 실제 원작 이름과 충돌하지 않게.
  - **새 세계**(코프룰루·심해·판게아 고유 지역)를 여는 배치: 판게아 고유 이름(아래 규칙).
- 몬스터 이름: 1~9자 한국어(띄어쓰기 포함). 원작 몬스터는 원작 표기(`파란 달팽이`, `블루 드래곤 터틀`). 판게아 고유 몬스터는 `[수식어]+[본체]` 구조(`가시등갑 게`, `열수 게`). 변종·특별 개체는 `[형용]+[원본]`(`다크 스톤골렘`, `대왕 까미`). “~왕”, “~군주”, “~의 그림자”는 보스·희귀 등급에만.
- 몬스터 id: 영문 camelCase. 지역 접두사 관례 `aq`(아쿠아로드) `lf`(리프레) `tt`(시간의 신전) `ar`(아케인 리버) `onyx`(칠흑 보스) `king`(대왕). 세이브·그림 파일 이름이므로 한 번 정하면 바꾸지 않는다.
- 아이템 이름: 장비 이름은 (부위 × 등급 7단계)마다 하나뿐이고 등급 = 세트(초보자 → 메이플 → 자쿰 → 파프니르 → 앱솔랩스 → 아케인셰이드 → 제네시스). 등급이 올라갈수록 수식어가 구체적 사물 → 추상 개념으로(목검·하얀 반팔 면티 → 제네시스 세이버·에테르넬 아머). 옵션 이름은 1~5자 명사(맹공·신비·유리 대포·피의 계약). 칠흑 장신구는 원작 아이템명.
- 스킬 이름: 1~12자, 원작 스킬명 표기(발도·애로우 블로우·파이널 피규레이션). 판게아 고유 스킬은 동작이 떠오르는 명사형(연속 베기·조류 역류). 5차는 ‘4차 이름 (5차)’처럼 묶지 않고 고유 이름.
- 지역 이름: 화면 이름은 `지역 · 장소`. 장소는 `[특징]+[지형]`(조개 해안·불타는 땅 화구호·소멸의 여로). 영문 부제 `REGION · PLACE`. 무리 서식지는 `지역 · 무리 서식지`로 자동.
- 직업·계보 이름: 원작 차수별 이름, 차수별 이름이 없는 직업은 ‘직업 (N차)’, 5차는 ‘4차 이름 (5차)’(`game/data/maple-names.ts` 규칙).
- 스토리 장면 제목: 2~11자 명사구(`선착장에서 눈을 뜨다`, `승천`). 장 제목은 `제N장 · 제목`.

## 6. 수치 밸런스 가이드 (코드에서 역산한 공식)
수치 필드를 직접 적지 말아야 할 곳과 적어도 되는 곳을 나눈다. **몬스터 능력치·경험치·골드는 레벨 하나로 전부 공식 계산**되므로 적지 않는다. 적어도 되는 것은 희귀 몬스터의 출현 가중치·보상 배율, 스킬 수치, 옵션 base, 던전 보상이다.

### 6.1 레벨 구간과 티어
- 플레이어 Lv.1~100(환생 46회부터 목표 Lv.100), 몬스터 Lv.1~106(검은 마법사). 10레벨 단위 ‘티어’는 키트 편의 개념이고 게임에는 없다.
- 게임의 **난이도(tide/tier)**는 사냥터마다 플레이어가 올리는 0~200 단계(환생 횟수 상한)이며, 몬스터 정의와 무관하게 전투 때 곱해진다.
- 사냥터 입장 레벨·환생 흐름: Lv.1 → 5 → 10 → 14 → 18 → 24 → 26 → 34(환생 1) → 46(2) → 55(5) → 70(10) → 80(15) → 90(15) → 100(20) → 코프룰루 100~106(환생 50~65). **몬스터 레벨은 Lv.110이 사실상 상한**(플레이어 Lv.100 + EXP_LEVEL_GAP 10 위로는 경험치가 같음). 그 위 깊이는 레벨이 아니라 입장 환생 · 난이도 · 변종 minTier로 둔다.

- **출현 가중치**(서버 전용 `game/secret/odds.ts ODDS.spawn`, common = 1 기준) / **보상 배율**(rewardMultiplier):

  | common | 1 (적지 않음) | 1 | 달팽이·돼지·와일드보어 |
  | rare | 0.10~0.18 (배수로 0.6) | 1.35~1.55 | 파란 버섯 .18/1.35 · 파이어보어 .14/1.5 |
  | epic | 0.04~0.08 | 1.75~2.8 | 좀비버섯 .07/1.75 · 레이스 .06/2.8(난이도 20+) |

### 6.4 장비·드롭
- 등급 7단계(= 옵션 줄 수): 일반 0 · 희귀 1 · 영웅 2 · 전설 3 · 신화 4 · 고대 5 · 태초 6. 위력 계수 1 / 1.5 / 2.2 / 3.3 / 3.9 / 4.5 / 5.2.
- 드롭 확률: 처치당 기본 **0.25%**(상한 3%, 드롭 보너스 × (1 + 보너스/0.1)). 던전은 처치 드롭 없음(첫 정복·무릉 5층마다 확정).
- 드롭 등급 분포(희귀부터, 일반은 안 떨어짐): 희귀 50.3% · 영웅 26.1% · 전설 14.1% · 신화 7.0% · 고대 2.4% · 태초 0.054%(천장 3,200회). 난이도 t마다 (1+0.0014t)^(등급−1)로 위로 민다(태초는 ×1.5까지).
- 드롭 장비 레벨 = max(몬스터 레벨, min(몬스터 레벨 + 5×난이도, 내 레벨 + 10)). power = round((레벨+2) × 등급 계수 × 0.8~1.2).
- 판매가 = 레벨별 몬스터 골드(상한 Lv.65) × [2, 6, 18, 50, 120, 300, 700][등급]. 분해 정수 = [1, 2, 4, 8, 16, 32, 64][등급].
