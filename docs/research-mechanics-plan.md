# 규칙을 바꾸는 연구 기획안 — ‘시스템 파괴 I’ 계열 확장

> 작성 2026-10-09 · 기준 v3.200
> 상태: **칠흑 추적 · 칠흑 소환 도입 결정(운영, 2026-10-09) · 미구현.** 나머지 후보는 제안(미결정)입니다.
> 개정 1: 운영 방향(“칠흑을 떨구는 보스 확정 출현 같은 것”)에 맞춰 콘텐츠 규칙 연구(1부)를 본안으로 올리고, 모든 후보에 작업량 · 구조 변경 여부를 붙였습니다.
> 개정 2: 칠흑 추적 · 칠흑 소환 도입 결정, 소환 비용은 세계석. 두 연구의 상세 규칙 · 구현 계획(4절)을 정리했습니다.

## 0. 요약

- **도입:** 칠흑 추적(출현 천장 단축, 3단계) · 칠흑 소환(호루라기로 칠흑 보스 호출, 3단계, 회당 세계석).
- 둘 다 끝까지 사면 칠흑 출현이 약 **×2.1**입니다. 장신구 1개 기대는 18일 → 약 9일, 7종 완성은 반년 → 약 3달입니다.
- 세계석 소비: 연구 가격 합계 **66,000** + 소환 회당 **100**(하루 최대 300). 엔드 하루 수입(사냥 8~12시간, 약 1,000~1,500) 기준 연구는 1.5~2달치이고, 소환은 하루 수입의 20~30%를 계속 씁니다. 보류 중이던 엔드 세계석 소비처(research-review 권고 3)를 겸합니다.
- **작업량 둘 다 작음~보통, 구조 변경은 상태 필드 하나**(소환 하루 횟수)뿐입니다. 칠흑 보스를 판정 없이 세우는 길(`spawn`의 `force === 'onyx'`)과 지역별 출현 천장 카운터(`onyxSeen`)가 이미 있습니다.

## 2. 칠흑 지금 규칙 (기준 숫자)

| 항목 | 값 | 위치 |
|---|---|---|
| 출현 | 무리 서식지 출현마다 0.3% × (1 + 난이도/50), 2,000번 못 보면 확정 | `secret/odds.ts` onyx(서버 전용) |
| 출현 수 | 서식지 방치 시 출현 약 180회/시간 → 칠흑 약 13회/일(난이도 0) | `data/onyx.ts` 머리 주석 |
| 드롭 | 격파마다 0.3%, 400번째 연속 미획득 격파는 확정 | 같은 곳 |
| 장신구 1개 | 기대 약 234격파 = 약 18일 · 최장 약 31일, 7종 완성 반년 남짓 | `data/onyx.ts` |
| 머무는 턴 | 80턴 안에 못 잡으면 떠남(보상 없음) | `ONYX.turns` |
| 어느 보스 | 서식지 **지역**마다 정해진 1종 | `onyxBossFor(region)` |
| 중복 | 각성(최대 5단계, 고유 옵션 +10%씩) → 다 차면 세계석 5 | `onyx-grant.ts` |

- **출현 천장 2,000은 사실상 작동하지 않습니다.** 평균 333번에 나오고, 2,000번까지 못 볼 확률은 0.25%입니다. 그래서 천장을 낮추면 그대로 “확정 출현이 빨라짐”이 됩니다.
- 확률 · 천장 수치는 **서버 전용(비공개)**입니다(v3.52). 화면에는 비공개가 꺼져 있을 때만 수치가 나갑니다(`oddsKnown()`, `secret/leaks.ts`).

## 3. 도입 연구 상세

### 3.1 칠흑 추적 — 출현 천장 단축 (도입)

| 항목 | 내용 |
|---|---|
| id · 이름 | `onyxTrack` · 칠흑 추적 |
| 탭 · 묶음 | 유틸 · 특별 |
| 단계 | 3 |
| 규칙 | 칠흑 출현 천장(못 본 출현 수)을 단계마다 낮춤: 2,000 → **600 · 450 · 300** |
| 조건 | 환생 30 |
| 가격(세계석) | **3,000 · 8,000 · 20,000** (합계 31,000) |
| 설명 문구 | 비공개 켜짐: “칠흑의 보스 출현 천장이 줄어듭니다(단계마다 더 빨리 확정).” 비공개 꺼짐: 단계별 천장 수치까지 표시 |

효과(난이도 0):

| 단계 | 천장 | 평균 출현 간격 | 출현 속도 | 장신구 1개 기대 |
|---|---|---|---|---|
| 지금 | 2,000 | 333 | ×1.00 | 약 18일 |
| I | 600 | 278 | ×1.20 | 약 15일 |
| II | 450 | 247 | ×1.35 | 약 13일 |
| III | 300 | 198 | ×1.68 | 약 11일 |

- 난이도를 올리면 기본 확률이 커져 천장이 덜 작동하므로, 높은 난이도에서는 효과가 줄어듭니다(난이도 50에서는 기본 출현이 이미 2배라 III단계도 약 ×1.2). 난이도 0 방치형에게 가장 크게 듣습니다.
- 부재중 정산도 같은 천장을 씁니다(지금도 사냥과 같은 `onyxChance`를 씀).

### 3.2 칠흑 소환 — 호루라기로 칠흑 보스 호출 (도입)

| 항목 | 내용 |
|---|---|
| id · 이름 | `onyxCall` · 칠흑 소환 |
| 탭 · 묶음 | 유틸 · 특별 |
| 단계 | 3 (하루 소환 횟수 1 · 2 · 3) |
| 규칙 | 전투 화면 호루라기 메뉴에 ‘칠흑의 보스’를 더함. 불면 다음 무리 서식지 출현이 그 지역 칠흑 보스가 됨 |
| 조건 | 환생 50 |
| 가격(세계석) | 연구 **5,000 · 10,000 · 20,000** (합계 35,000) + 소환 **회당 세계석 100** |
| 하루 횟수 | 연구 단계만큼. 까미 · 누리 · 슬라임 호루라기(SP 5, 하루 3회)와 **따로** 셈 |

효과: 하루 자연 출현 약 13회에 +1 · 2 · 3회 → 출현 속도 ×1.08 · ×1.15 · ×1.23. 칠흑 추적과 곱으로 쌓입니다(둘 다 III면 ×1.68 × ×1.23 ≈ **×2.07**).

세부 규칙(구현 때 이대로):
1. **무리 서식지에서만 불 수 있습니다.** 던전 · 랜덤게임 · 일반 사냥터에서는 막습니다(기존 호루라기의 던전 제한과 같은 방식).
2. **불고 나서 서식지를 떠나면 소환은 남아 있다가**, 다음 서식지 출현에서 나옵니다. 세계석은 불 때 냅니다. 지금 호루라기는 다음 출현에 무조건 소모되는데, 칠흑은 서식지가 아니면 나올 수 없어 그대로 두면 세계석만 사라지기 때문입니다.
3. **소환한 칠흑은 출현 천장 카운터를 건드리지 않습니다.** 지금 `force === 'onyx'` 분기는 카운터를 0으로 되돌립니다. 그대로 두면 천장에 가까울 때 소환하면 손해이므로, 호루라기로 부른 경우만 카운터를 유지합니다(부재중 정산이 쓰는 `force`는 지금처럼 0으로).
4. 칠흑 · 일반 호루라기는 동시에 하나만 걸어 둘 수 있습니다(지금 규칙 “이미 호루라기를 불었습니다” 그대로).
5. 소환한 보스도 자연 출현과 같습니다: 머무는 턴 80, 드롭 확률 · 드롭 천장, 각성 · 세계석 중복 처리 모두 같습니다.
6. 하루 기준은 기존 호루라기와 같은 날짜 키(`dayKey`)입니다.

세계석 100의 근거: 소환 한 번은 장신구 진행의 약 1/234(격파 1회)입니다. 하루 3회면 300개로, 엔드 하루 수입의 20~30%를 계속 쓰는 소비처가 됩니다. 연구 가격만 내고 소환을 공짜로 두면, 연구를 다 산 뒤에는 소비처 역할이 끝납니다.
