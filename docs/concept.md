# TIDEBOUND 기획안 v2 — 무너진 세계들의 RPG (초안)

> 상태: **초안**. 게임 데이터는 아직 바꾸지 않았다. 아래 "결정할 것"이 정해지면 단계별로 반영한다.
> 기존 세계관 한 장(`docs/world.md`)은 이 기획안의 **첫 번째 세계(심해)** 로 그대로 살아남는다.

## 0. 지식재산권 원칙
디아블로·메이플스토리·스타크래프트·워크래프트에서 가져오는 것은 **장르의 재미와 분위기**뿐이다.
- 쓰지 않는다: 작품·회사 이름, 캐릭터·종족·직업·지명·아이템 고유 이름, 설정 문장, 로고·그림·음악·효과음, 이를 흉내 낸 패러디 이름.
- 쓴다: 장르 문법(핵앤슬래시 파밍, 전직 성장, 종족 대전, 진영 서사), 일반 명사(악마, 성기사, 기계, 군체, 용 등), 우리가 지은 고유 이름.
- 소개 문구에도 다른 게임 이름을 넣지 않는다("○○ 같은 게임" 표현 금지). 홍보는 "여러 세계를 넘나드는 궁극의 RPG"로 한다.

## 1. 한 줄 콘셉트
**여러 세계가 한꺼번에 무너져 서로 뒤엉킨 곳에서, 모험가는 생을 거듭하며 모든 세계의 힘을 손에 넣는다.**
장르가 다른 다섯 세계가 균열로 이어져 있고, 세계마다 사냥 방식·적·보상의 맛이 다르다. 한 캐릭터가 모든 세계를 오가며 직업과 스킬을 섞어 쓰는 것이 이 게임의 "궁극"이다.

## 2. 다섯 세계
| 세계 (가칭) | 장르 감성 | 핵심 재미 | 지금 시스템과의 연결 |
|---|---|---|---|
| **심해** — 끝없는 바다 | 기존 TIDEBOUND | 낚시 비유의 방치 사냥, 변종·무리 | 지금의 낚시터·어종·까미 그대로 |
| **잿빛 성역** — 타락한 대성당과 지옥문 | 다크 판타지 핵앤슬래시 | 등급 장비 파밍, 옵션 조합, 균열 무한 하강 | 장비 등급·옵션, 무한 심연 → "지옥 균열" |
| **꽃구름 섬** — 둥실 떠 있는 동화 마을 | 아기자기한 성장 모험 | 1~5차 전직, 귀여운 몬스터, 파티 보스 | 직업 트리·전직, 길드, 결투 |
| **철의 궤도** — 별 사이 전장 | SF 종족 대전 | 세 종족(기계 문명·생체 군체·초능력 종족) 중 하나와 계약, 소환·물량 스킬 | 결투 시즌, 길드 주간 목표, 무리(물량) 시스템 |
| **오래된 대륙** — 왕국과 부족의 땅 | 하이 판타지 영웅 서사 | 두 진영(왕국 연합·대지의 부족) 선택, 레이드 던전, 영웅 칭호 | 던전 보스·첫 정복 연구, 칭호, 진영별 랭킹 |

- 세계 이름·종족 이름·진영 이름은 모두 가칭이다. 확정할 때 다른 작품과 겹치는 이름이 없는지 검색해 확인한다.
- 세계마다 사냥터 3~4곳과 던전 1~2곳을 둔다. 적 능력치와 보상 공식(v27.34~27.36의 골드 곡선·던전 보상·장비 배율)은 모든 세계가 같이 쓴다. 세계는 **분위기와 특수 규칙**이 다를 뿐 수치 체계는 하나다.

## 3. 세계를 잇는 장치
- **균열(지금의 무한 심연)**: 모든 세계 밑바닥이 이어진 곳. 층마다 다른 세계의 적이 섞여 나온다. v27.35 난이도 공식 그대로.
- **환생 → 세계 순환**: 한 생을 마치면 "세계의 핵"(지금의 진주)을 얻고 처음 세계로 돌아온다. 환생 횟수에 따라 세계가 열린다(심해는 처음부터, 꽃구름 섬은 Lv.10, 잿빛 성역은 환생 1회 등).
- **직업 섞기**: 세계마다 고유 직업 계보가 있고, 계승으로 다른 세계 스킬을 가져와 섞는다(지금의 계승·AP 시스템).
- **공용 성장**: 레벨·능력치·연구·도감은 세계와 상관없이 하나다.

## 4. 지금 게임에서 바뀌는 것과 남는 것
| 영역 | 남는 것 | 바뀌는 것 |
|---|---|---|
| 전투·성장 | 자동 전투, 스킬 편성, 숙련, 환생, 연구 | 없음 |
| 용어 | 심해 세계 안에서는 낚시 비유 유지 | 다른 세계에서는 "사냥·처치·전리품" 같은 일반 용어 |
| 첫 화면·소개 | — | 부제 "심연의 낚시꾼" → 새 부제(가칭 "무너진 세계들"), 설명 문구 |
| 데이터 | 기존 낚시터 10곳·던전 8곳 | 세계 구분 필드 추가, 세계별 사냥터·적·던전 추가 |
| 그림 | 기존 어종·직업 그림 | 세계별 새 적·배경 그림(원작 그림 참고·모작 금지) |

## 5. 단계 계획
1. **0단계: 이름과 소개** — 부제·소개 문구·도움말의 게임 설명을 새 콘셉트로. 심해 세계는 그대로.
2. **1단계: 세계 구분** — 낚시터·던전에 "세계" 필드를 넣고 화면에서 세계별로 묶어 보여 준다. 기존 콘텐츠는 모두 심해.
3. **2단계: 첫 새 세계 1곳** — 사냥터 3곳·던전 1곳·적 12종·직업 계보 1개. 수치는 기존 공식으로 자동 산출.
4. **3단계 이후**: 나머지 세계를 하나씩, 진영·종족 선택, 균열에 세계 혼합.

## 6. 결정할 것
1. **낚시의 위치**: 심해를 다섯 세계 중 하나로 남길지, 낚시 비유를 게임 전체에서 걷어낼지.
2. **게임 이름**: TIDEBOUND를 유지할지(바다 이미지가 강함), 새 이름을 지을지.
3. **첫 새 세계**: 어느 세계부터 만들지.
4. **진영·종족 선택**: 한 번 고르면 고정할지, 환생 때 바꿀 수 있게 할지.
