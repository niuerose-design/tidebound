# TIDEBOUND · 심연의 낚시꾼

행동력 없는 낚시 테마 방치형 RPG. React + TypeScript 화면, 순수 함수 전투 엔진, Cloudflare Workers API, D1 영구 저장으로 구성합니다. 원작 소스나 자산을 복제하지 않고 요청한 시스템을 독립적으로 구현했습니다.

## 플레이

자동 낚시를 시작하면 2초마다 플레이어와 물고기가 행동합니다. 매 턴 액티브 스킬을 장착 순서대로 판정해 처음 성공한 하나를 사용하며, 모두 실패하면 기본 공격합니다. 한 스킬의 표기 발동률은 앞 스킬들이 실패했을 때의 조건부 확률입니다. 재사용 대기 중인 스킬은 판정하지 않습니다. 상태이상은 명중 시 적용되며 기절은 상대의 한 행동을 건너뛰고, 침묵은 액티브만 막고, 감속·가속은 다음 라운드의 선공 우선순위를 바꿉니다. 회복은 최대 체력 22%입니다. 전투 승리 후 체력 16%가 회복됩니다. 패배하면 손실 없이 3턴 동안 회복합니다.

- 낚시터 9곳 / 물고기 35종 이상(희귀·영웅·전설 보스 포함) / 5연전 던전 7곳(단계형 무한 심연 포함) / 길드 레이드 / 도움말·패치 노트
- 스킬 103종(환생·히든·몬스터 계열 직업 스킬 포함) / 액티브·패시브 개수 제한 없음, 총 AP 한도 내 장착
- 상태이상 6종: 기절(행동 차단), 침묵(액티브 차단), 약화(피해 감소), 출혈(지속 피해), 감속·가속(선공 우선순위 변화)
- 작살 사냥꾼·조류술사·산호 수호자·기타 4대 직업 트리. 레벨 10 독립·입문 직업과 레벨 25·40 상위·히든·파밍·몬스터 계열 직업 69종. 1·2차 직업은 전용 스킬 1~2종으로 분산
- 첫 환생 레벨 30을 약 6시간 자동 낚시 목표로 조정했으며, 이후 환생마다 필요 레벨 +5(최대 60). 진주 = floor(레벨/10) + 이전 환생 횟수 + 진주 연구/숙련 보너스
- 낚싯대·방어구·나침반, 일반/희귀/영웅/전설 4등급, 가방 60개
- 도감 포획 50·500·2,500·10,000회마다 골드 보상, 마지막 10,000회에만 종별 1 SP. 한 종 50회 연구를 지역 완성 기준으로 삼으며, 지역 연구 완료마다 AP +1과 최대 체력 +20
- 서버 시간 기준 최대 2시간 부재중 실제 턴 시뮬레이션
- 던전 보상: 반복 골드·희귀 이상 장비, 일반 던전 진주는 최초 정복만, 무한 심연은 새 깊이마다 지급
- 비동기 PvP: 등록 시점의 상대 능력치·스킬로 결투, 명중·회피 포함 최대 80턴, 1분 간격
- 데이터 초기화: 환생 화면에서 이름을 제외한 진행·길드·랭킹 등록 정보를 새 게임처럼 지울 수 있습니다.
- 훈련 NPC는 실제 랭킹과 분리, 재화·점수 변화 없음

### 예: 물고기 추가

`world.ts`의 `rows`에 `[고유ID, 표시이름, 레벨, 설명]`을 추가하고 원하는 `STAGES[].fish`에 그 ID를 넣습니다. 기본 스탯은 레벨 공식에서 산출합니다. 희귀종은 `rarity`, `spawnWeight`, `rewardMultiplier`를 지정하고, 던전 마지막 웨이브는 `DUNGEONS[].bossFish`로 별도 보스를 연결합니다. UI 도감은 같은 데이터를 읽어 자동으로 표시합니다.

### 예: 스킬 추가

`skills.ts`에 Skill 형식 객체를 추가합니다. `type`, `level`, 선택적 `job`, `chance`, `cooldown`, `multiplier`를 설정합니다. 기존 효과는 `heal`, `stun`, `bleed`, `weaken`, `drain`, `silence`, `slow`, `haste`입니다. `statusTurns`로 상태 지속시간을 스킬별 조정할 수 있고, `extraAttacks`·`extraAttackMultiplier`로 제한된 추가타를 선언할 수 있습니다. 패시브 `bonus`에는 `goldBonus`, `dropBonus`, `dungeonGoldBonus`, `rebirthBonus`를 사용할 수 있습니다. `cost`는 장착 AP, `manaCost`는 발동 시 마나 비용입니다. 새로운 상태이상은 types와 combat의 처리기를 함께 확장합니다. 발동률은 0~1 사이입니다. 표시 이름만 바꿀 때는 기존 `id`를 유지하세요.

`masteryMilestones`는 성장 Lv.1부터의 **누적 숙련도**입니다. 승리당 기본 1이며 조건부 보너스를 받으면 최대 10까지 오릅니다. 배열 길이가 최대 성장 레벨이며, `rankEffects`는 단계당 변화량입니다. 망인의 골격처럼 단계마다 페널티가 보너스로 뒤집히는 스킬은 `levelEffects`에 기본 Lv.0부터 각 단계의 AP·능력치를 명시합니다. 음수 AP는 이 명시적 단계 설정에서만 허용합니다. 파일 하단의 직업별 기본 곡선과 소유 직업 재배분도 함께 확인하세요.

경험치 패시브는 `bonus.expBonus`에 0.1처럼 가산 비율을 지정합니다. 직업 자체 보너스는 `Job.expBonus`입니다. 환생·연구·직업·장착 패시브를 합친 `stats().expBonus`가 표시와 보상 양쪽에 적용됩니다. `masteryGain`은 `bossOnly`, `enemyIds`, `bonusByLevel`로 조건과 성장 단계별 추가 숙련을 설정합니다. 조건이 겹치면 가장 큰 값 하나만 적용하고 도감·포획 수·SP는 늘리지 않습니다. `unlockJobMastery`는 최초 스킬 습득에 요구하는 소유 직업 숙련도로, SP로 건너뛸 수 없습니다. `sourceEnemySkill`은 원본 몬스터 기술 ID입니다.

직업 관리용 데이터는 `node scripts/export-game-content.mjs /absolute/path/content.json`으로 내보낼 수 있습니다. 실제 전투에 적용되는 직업 배율과 모든 스킬 성장 단계를 포함합니다. 엑셀 수정은 게임 코드로 자동 반영되지 않으며, 원장과 성장 표의 확정 내용을 위 데이터 파일에 적용한 뒤 다시 검증·내보내기 하세요.

### 저장 호환성

저장 `version`은 현재 5입니다. `game/systems/migrations.ts`가 v1~v4 기록을 자동 이전합니다. v4→v5 이전에서는 기존 SP 잔액·실제 투자액·해금 기록·숙련 승수·장비·도감을 보존하고, 현재 직업의 미해금 스킬을 무료로 지급합니다. 직업 재배분에 따라 사용할 수 없거나 AP를 초과하는 편성은 일부 해제되지만 스킬 기록을 삭제하지는 않습니다. SP 계승 여부는 `skillInheritances`에 별도 저장합니다. `learned`의 1은 무료 기본 스킬이며, 2부터 SP로 연 성장 단계입니다. 실제 성장 레벨은 SP와 숙련 중 높은 값 하나만 적용합니다.

기존 ID 삭제, 상태 필드 제거, 저장 구조 변경 시 서버 로딩에 마이그레이션을 추가해야 합니다. 밸런스 데이터 숫자·이름을 바꾸는 것은 보통 저장 구조 변경이 아닙니다. 장비는 획득 당시 수치가 저장되며, 이미 등록한 PvP 방어 정보도 자동 재계산되지 않습니다. 변경 뒤 전투 정보 재등록이 필요합니다.

## 서버와 저장

클라이언트는 '행동'만 보내며 레벨·골드·피해량을 직접 제출하지 않습니다. 서버가 경과 시간을 계산하고 순수 게임 엔진으로 판정한 뒤 저장합니다. `players.revision` 조건부 UPDATE로 동시 탭의 중복 보상이나 구매를 방지합니다. 실패한 요청은 상태를 확정하지 않습니다. GET 랭킹은 읽기 전용입니다.

`players`: 계정별 JSON 상태, revision, 수정 시간. `rankings`: 명시적으로 등록한 방어 스냅샷, 결투 점수, 전투력, 등록 시간. D1 쿼리는 바인딩된 prepared statement를 사용합니다. DB 오류 시 UI에서 다시 연결할 수 있고, 로컬 저장을 서버 저장인 것처럼 표시하지 않습니다.

현재는 소유자 전용 Sites 배포입니다. 계정은 플랫폼이 전달하는 인증 사용자 ID로 구분됩니다. 다른 참가자를 받으려면 Sites 접근 설정을 변경해야 합니다. 외부 호스팅으로 이전할 때는 `identity()`를 검증된 세션/JWT 인증으로 대체하세요. 인터넷에 직접 노출된 서버에서 요청 헤더만 믿으면 안 됩니다. 개발 모드에서만 `local-preview-player`를 사용합니다. 프로덕션 빌드에서는 인증 없는 요청에 401을 반환합니다.

### PvP 규칙과 범위

상대의 등록된 능력치·최대 체력·스킬로 독립 전투를 만들며 PvE 체력을 차감하지 않습니다. 등록자는 현재 스킬의 패시브가 포함된 최종 스탯을 저장합니다. 전투에서는 이를 다시 더하지 않습니다. 속도가 높은 쪽이 선공하며 동률이면 매 턴 교대하고 80턴 경과 시 무승부입니다. 점수는 Elo 기대승률(K=24)에 따라 **도전자만** 변합니다. 방어자는 오프라인일 수 있어 점수를 차감하지 않는 비대칭 사다리입니다. 시즌 초기화·매칭·다계정 방지·경쟁 서비스용 속도 제한은 후속 확장 대상입니다. 실제 유저가 없을 때의 NPC는 '훈련 상대'에만 표시합니다.

## 개발과 실행

Node 22.13 이상과 pnpm을 사용합니다. lockfile을 유지하세요.

```sh
pnpm install
pnpm build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_futuristic_onslaught.sql
pnpm dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. `index.html`을 더블클릭하는 형태가 아니라 API와 DB를 함께 실행하는 프로젝트입니다. DB 초기화는 첫 실행 한 번만 필요합니다.

Sites 관리 환경에서는 감독형 미리보기 `sites-preview start /absolute/path/to/project`를 사용합니다.

```sh
node node_modules/typescript/bin/tsc --noEmit
node tests/run.mjs
pnpm run db:generate
pnpm build
```

로컬 D1 초기화(첫 실행 한 번, 생성한 최신 파일명에 맞춤):

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_futuristic_onslaught.sql
```

`db/schema.ts` 변경 시 Drizzle migration을 새로 생성하고 SQL을 검토합니다. 적용한 마이그레이션 파일과 메타데이터는 수정하지 마세요. Sites 배포는 `.openai/hosting.json`의 D1 선언을 이용해 마이그레이션을 적용합니다. 다른 호스팅에서는 같은 스키마와 원자적 revision 업데이트를 유지하는 DB 어댑터가 필요합니다. 정적 HTML만 업로드해서는 현재 API/저장/랭킹이 동작하지 않습니다.

### 현재 성장 규칙 · 17.0

- 근력·기민·지능·체질·정신·행운에 시작 4포인트, 레벨마다 4포인트를 배분합니다. 전투를 멈추면 무료 재분배 가능합니다.

- 시작 SP와 레벨업 SP는 0입니다. 종별 도감 10,000회 보상의 1 SP가 신규 공급처이며, 종마다 한 번만 받습니다. 기존 버전에서 얻은 SP는 회수하지 않습니다.
- AP는 행동력이 아닌 총 장착 한도입니다. 기본 6 + 지역 연구마다 1 + 환생당 1(최대 12) + 진주 AP 연구(최대 12)입니다. 액티브·패시브 개수 자체는 제한하지 않습니다.
- 얻은 직업 스킬의 계승은 1 SP, 성장 한 단계 강화도 1 SP입니다. 두 행동은 별개이며 SP 강화만으로 계승되지는 않습니다. 현재 직업 또는 계승한 스킬만 강화할 수 있습니다.
- 장착 승리로 첫 숙련 목표에 도달하면 무료 계승과 성장 Lv.1을 얻습니다. 이후에도 숙련으로 무료 성장합니다. SP와 숙련은 같은 성장 단계이며 효과를 합산하지 않습니다. SP를 써도 숙련은 계속 쌓이고, 전직 선행조건에는 실제 승리 숙련만 인정합니다.

- 1차 기본 숙련 곡선은 누적 250·1,200·4,500·14,000, 2차는 600·3,000·12,000·36,000, 3차는 1,500·7,500·28,000·75,000입니다. 대기만성·AP 절감 등은 더 긴 개별 곡선을 사용합니다. 간단히 보기와 자세히 보기 모두 현재 숙련도·다음 목표·최대 레벨을 표시합니다.

- 우선순위는 기존처럼 위에서부터 유지합니다. 전투 화면은 편성한 모든 액티브를 보여주며, 조건·쿨다운·마나·확률을 순서대로 확인하고 첫 성공 스킬을 사용합니다. 따라서 액티브를 많이 넣어도 AP를 소모하고 우선순위가 내려가므로 조합 선택의 비용이 남습니다.
- 물고기 종별 완성은 더 이상 AP를 직접 주지 않습니다. 모든 종을 10회씩 연구한 지역이 AP +1과 최대 체력 +20을 줍니다.
- 도감 SP 단계는 1·20·80·250회, 보상은 1·1·2·3 SP로 조정하여 초반 SP 폭증을 줄였습니다. 수치는 `game/data/balance.ts`와 `game/data/progression.ts`에서 조정할 수 있습니다.

### v6 직업 트리·결투·초기화

- SP 랭크와 숙련 무료 강화는 한 스킬에서 중첩되지 않습니다. 두 번째 SP 강화를 누르면 SP 경로가 적용되고, SP를 쓰지 않은 스킬은 숙련 경로로 강화됩니다. 스킬 초기화 후 다시 선택할 수 있습니다.
- 직업 화면에 네 갈래 트리와 상세 노드 패널을 추가했습니다. 기타 트리에는 체력·마나 비례 스킬과 환생 히든 직업이 있습니다.
- 비동기 결투는 등록된 스냅샷의 명중·회피를 양쪽 전투에 적용하고, 결과에 실제 명중률과 관련 스탯을 표시합니다.
- 환생 화면의 데이터 초기화는 자동 낚시·던전을 멈춘 뒤 이름만 남기고 플레이어·길드·랭킹 등록 정보를 초기화합니다.
- 경험치 곡선을 1.175 성장률로 조정해 첫 환생 목표를 일반적인 자동 낚시 기준 약 1~1.5시간으로 맞췄습니다.

### v7 스킬 경로·망인 직업군

- 한 스킬의 강화는 SP 경로와 숙련 경로 중 하나만 적용됩니다. 랭크 2 이상의 SP 강화를 선택하면 해당 스킬은 SP 수치만 사용하며, 초기화 후 다른 경로를 고를 수 있습니다.
- 스킬 화면은 현재 직업·공용·전체 필터와 간단히 보기·자세히 보기로 나뉩니다. 간단히 보기에는 핵심 수치와 호버 툴팁만, 자세히 보기에는 다음 강화 변화·숙련 보상·진행도가 표시됩니다.
- 기타 트리에 망인·해골 기사·골령술사를 추가했습니다. 기본 명중·마나·저항 또는 방어 페널티가 있지만, 골격 패시브를 끝까지 숙련하면 AP와 최대 체력 보상을 얻습니다. 기타 트리의 직업 숙련 목표는 장기 발견 콘텐츠로 설계되어 있습니다.
- 직업과 스킬 데이터는 `game/data/classes.ts`, `game/data/skills.ts`에서 확장할 수 있으며, 화면은 데이터 배열을 자동으로 읽습니다.

### v8 직업 항해도 확장

- 직업 수를 41종, 스킬 수를 84종으로 확장했습니다. 네 트리마다 중립적인 1차 분기, 방향성이 있는 2차 분기, 대가가 큰 3차·히든 분기를 배치했습니다.
- 1차 직업은 보정을 거의 주지 않고 일부 페널티를 동반합니다. 상위 직업으로 갈수록 HP·MP 비례, 관통·흡혈, 치명·회피, 회복·기절 등 명확한 빌드 목적을 갖습니다.
- 직업마다 스킬 수는 고정하지 않았습니다. 산호 성인처럼 패시브 2개만 가진 직업, 조수 투사처럼 액티브 1개만 가진 직업, HP·MP 비례 액티브와 패시브를 함께 가진 직업이 공존합니다.
- `game/data/classes.ts`의 `JOBS.push`와 `game/data/skills.ts`의 신규 데이터 묶음에서 직업명·조건·수치·스킬을 직접 수정할 수 있습니다.

### v9 전직 조건·숙련 곡선

- 상위 직업은 부모 직업 숙련 외에도 `requiresJobMastery`로 다른 직업 숙련을, `requiresSkillMastery`로 특정 스킬 숙련 단계를 요구할 수 있습니다.
- `masteryMilestones`가 없는 스킬은 기본 `[30, 60, 100, 150]`승을 사용합니다. AP 절감·HP/MP 비례·완성 보상 스킬은 `game/data/skills.ts`의 `masteryTuning`에서 45~400승으로 조정했습니다.
- 1차 독립 직업은 `branchless: true`로 표시하며 상위 자식 없이도 파밍·순환·생존·수집 등 자체 빌드를 완성할 수 있습니다.

### v11 희귀어·보스 원정·경제 직업

- 해류 측량사·인양 상인·진주 중개인·희귀어 추적자·심연 기록관은 전투 보정 대신 장비 드롭·골드·던전 골드·환생 진주를 스킬로 키우는 선택지입니다. 몬스터 계열인 폭풍 곰치 혈족과 크라켄 혈족은 보스 기술을 플레이어 스킬로 계승합니다.
- 스킬은 `extraAttacks`와 `extraAttackMultiplier`로 추가타를 만들 수 있습니다. 현재 전투 엔진은 한 행동당 최대 2회로 제한하고, 후속 타격도 명중·치명타·흡혈을 별도로 판정합니다.
- 속삭이는 해초림·검은 화산수역·별비의 외해를 추가했으며, 희귀도·출현 가중치·보상 배율이 있는 물고기와 7종 던전 전용 보스를 제공합니다.
- 던전 탐험 메뉴에서 웨이브 트랙, 보스 슬롯, 양쪽 HP/MP, 상태이상, 적 스킬 프로필과 최근 전투 로그를 확인할 수 있습니다. 보스는 개체도감의 별도 섹션에서 추적합니다.
