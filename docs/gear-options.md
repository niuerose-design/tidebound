# 장비 옵션 정리 (v3.73)

옵션 한 줄 한 줄이 쓸모 있게 옵션 종류를 정리합니다. 무엇을 남기고, 더하고, 합쳤는지와 다음에 고를 후보를 적습니다.

## 원칙

- **너프 없음.** 은퇴한 옵션은 새로 굴리지 않을 뿐이고, 이미 붙은 장비에서는 그대로 작동하고 표시됩니다(`retired`). 수치 재설정도 됩니다.
- **이중 옵션은 두 수치가 같은 굴림을 받습니다.** `rollBoth`이므로 두 수치에 같은 굴림과 등급 품질이 들어갑니다. 고정 수치는 둘째 값도 등급 감쇠를 받습니다.
- **기준 캐릭터.** 환생 200, Lv.100, 치명타 100%, 태초 22성 4부위(옵션 없음). 표의 "1줄"은 태초 평균 굴림 한 줄을 무기에 붙였을 때 전투력이 오르는 비율입니다.

## v3.73 반영

| 항목 | 내용 | 1줄 (물리 / 마법 기준) |
|---|---|---|
| 잔혹 · 파멸 | 수치는 그대로, 등장 가중치 0.4 (`AffixDef.weight`) | 잔혹 +2.7%, 파멸 +5.4% |
| 맹공 · 신비 | 유지 | 맹공 +3.6% / 신비 +3.1% |
| **위력** (신규) | 물리 공격 0.2 + 마법 공격 0.2 × 장비 위력 | +2.4% / +2.7% |
| 철갑 · 정신 | 유지 | 철갑 +1.8%, 정신 +10.2% |
| **수호** (신규) | 물리 방어 0.2 + 마법 방어 0.2 × 장비 위력 | +8.7% / +7.9% |
| **마력** (통합) | 최대 마나 0.2 + 마나 회복 0.012 × 장비 위력. 샘물 · 순환은 은퇴 | 전투력 0 (마법 직업 유지력) |
| **풍요** (신규, 고대 이상 전용) | 경험치 4% + 골드 5%. 학식(3%) · 황금(4%)은 그대로 | 파밍 |
| 피의 계약 | 흡혈이 장비 상한(10%p)과 전체 상한(30%)을 받지 않음. 한 번 회복량 상한은 그대로 | −1.1% (흡혈 +11.5%p 대 체력 −11%) |
| 도박수 | 유지 (치명 100% 전 캐릭터에겐 이득) | |
| 저격 뽑기 | 골드 랜덤 뽑기 ×2 → ×5, 정수 10 → 50 | |
| 신화 · 유물 | 신화 감쇠 .72 → .74, 유물 환생 성장 3.65 → 3.75 (0성 전설 < 신화, 환생 200 유물 > 신화 22성 유지) | |

치명 피해 옵션이 장비 1개에 붙을 확률:

| 등급 | 전 | 후 |
|---|---|---|
| 신화 (4줄, 잔혹) | 14.5% | 6.1% |
| 고대 (5줄, 잔혹 또는 파멸) | 29.5% | 13.5% |
| 태초 (6줄, 잔혹 또는 파멸) | 35.2% | 16.1% |

출처 테마에 들어 있던 샘물 · 순환은 마력으로 바꿨습니다. 저격 뽑기로는 고대 이상 전용 옵션(풍요 포함)을 고를 수 없습니다.

## 후보 B. 꽝 옵션 7종

모든 장비에 일정 확률로 끼어드는 거의 빈 줄입니다. 좋은 줄이 나왔을 때의 기쁨을 키우고 옵션 재설정의 이유가 됩니다.

권장 규칙:
- 각 줄이 굴릴 때 8% 정도로 꽝이 됩니다.
- 저격 뽑기로 고른 줄은 꽝이 안 됩니다.
- 수치 재설정으로는 못 바꾸고 옵션 재설정으로만 바꿉니다.
- 한 장비에 꽝은 최대 1줄입니다.

| # | 이름 (가칭) | 효과 |
|---|---|---|
| B1 | 무명 | 효과 없음 |
| B2 | 장식 | 효과 없음. 장비 이름 앞에 '반짝이는'이 붙음 |
| B3 | 한 줌 | 최대 체력 +1 (장비 위력과 무관한 고정 1) |
| B4 | 녹 | 판매 가격 +10% |
| B5 | 잔돈 | 처치 골드 +1 G 고정 |
| B6 | 무게 | 속도 −0.5 (작은 손해) |
| B7 | 잡음 | 명중 −1%p (작은 손해) |

B6 · B7처럼 작은 손해가 있는 꽝은 옵션 재설정을 하게 만드는 이유가 됩니다. 손해 없는 꽝(B1~B5)만 쓰고 싶으면 그것만 고르면 됩니다.
